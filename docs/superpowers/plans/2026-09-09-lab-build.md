# AWS Defense Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Create a complete reproducible repository and recorded-demo preparation workflow.
**Architecture:** Terraform bootstraps CI identity/state and deploys separate application and monitoring hosts. Host and CloudTrail logs converge in Wazuh with explicitly configured behavioral and synthetic IOC rules.
**Tech Stack:** Terraform >=1.10,<2; AWS provider ~>6.0; Python 3.10+; Wazuh 4.14; GitHub Actions.
**Spec:** docs/superpowers/specs/2026-09-09-lab-design.md

## Global Constraints
- One bounded lab scenario; no production data or long-lived AWS keys.
- No deployment from this build environment. Claims distinguish static/local tests from live validation.
- S3 backend lock files; state kept outside source control.
- User approved repository construction; proceed without repeated design approval.
